Grown-up corner · how levels work

90 puzzles: 30 per level, all starting empty. Each has six connected regions and exactly one solution, checked independently. Each was also solved from start to finish using logical deductions, with no trial placements or guessing.

Easy: find the only square left in a row, column, or region, then rule out squares blocked by that dog.
Medium: also consider all remaining positions in one group. If every possible position blocks a square, that square is out.
Hard: also consider two groups together. If every legal pair of dog positions blocks a square, that square is out.

A puzzle is placed in the lowest level that can solve it. Puzzles within each level are ordered by a deduction-work score; perceived difficulty can vary. On Medium and Hard, Hint highlights one next square and explains whether to tap once for × or twice for a dog. Dotted squares show the clues. You can make the move yourself or choose Apply this step. On Easy, Explain a move highlights a full logical step.

Single tap = ×; double tap = dog. One incorrect dog placement or an × on a dog’s correct square ends the game. Try again restarts the same puzzle. No ads, timer, or internet needed. Progress saves when browser storage is available. Keyboard: arrows to move, C for a dog, X for Not here, Delete to erase. Start over opens a confirmation over the board. Starting a new puzzle asks before replacing unfinished work.
